# 数宇宙 SU-KUKAN — 高校数学3Dアニメーション教材 企画書

## 1. コンセプト

**「数学は宇宙である」** — 高校数学の全単元を、ひとつの3D空間の「星図（Star Map）」として体験する。

学ぶ者が、紙のグラフから空間へ関数を持ち上げ、抽象式が実体を持つ瞬間を見る。
数式は星、証明は軌道運動、定理は空間の法則として現れる。

- ターゲット: 高校1〜3年生（数学I〜C 全82単元）、および再学習者
- 提供形態: ブラウザのみ。インストール不要。WebGL2
- 体験の核: 数式が「動く」と、定義が霧が晴れる瞬間

## 3. 機能要件

| # | 要件 |
|---|---|
| F1 | 星図: 6科目を6つの星雲、82単元を星として配置。クリックで飛行 |
| F2 | categorized_再生: 単元ごとに「ステップ」列。テキスト＋数式＋3Dアニメーション＋カメラワーク |
| F3 | インタラクション: パラメータ変更、ドラッグ、ステップ送り・戻し、再生速度 |
| F4 | 数式表示: KaTeX（DOMパネル）＋ Canvasスプライト（3D内ラベル） |
| F5 | 学習支援: キーボード操作、進捗の保存、再生速度、箇条書き目次 |
| F6 | 品質: 自動品質段階（解像度・Bloom・影）、モバイル対応モーション低減設定 |

## 4. システム設計

```
src/
  engine/    App Stage CameraRig Sequencer Label Materials Background MathUtil
  visuals/   16種のビジュアル・ビルダー（登録テーブル）
  content/   6科目82単元のスクリプト（データ駆動）
  ui/        StarMap Panel Controls
```

### ビルダー契約

各ビルダーは `params`（可変パラメータ）と `parts`（名前付きObject3D）を公開する。
シーケンサのステップは宣言的なアクションで操作する。

```js
{ d: 4, text:'…', math:'…', cam:{pos:[x,y,z], look:[x,y,z]},
  show:['curve'], hide:['grid'], set:{a:2}, focus:'vertex', note:['頂点'] }
```

### 領域ごとの視覚言語

| 教科領域 | 表現 |
|---|---|
| 関数・曲線 | 3Dプロットと平面への射影。変数を立体で読む |
| 図形 | 発光ワイヤフレームと面の回転・展開 |
| 数列 | 螺旋上の点列、伸びる棒 |
| 確率 | サンプリングする群衆、箱の中のボール、2^n の木 |
| 極限 | 収束する球、振動の可視化 |
| 微積分 | 接線プレーン、柱群から面積へ、回転体 |
| 複素数 | 複素数平面上の回転ベクトル、多項式の零点 |
| 二次曲線 | 円錐の平面切断。実空間での楕円・双曲線・放物線（本作の主役） |
| ベクトル・行列 | 格子変形としての線形写像 |

## 5. 開発計画

1. 基盤: Vite + three.js 0.169 + KaTeX + Playwright
2. エンジン: ステージ、背景、カメラリグ、シーケンサ、ラベル、素材
3. ビルダー16種を順に実装し、契約を確定
4. 70単元のスクリプトをデータ駆動で執筆
5. 星図、UI、検証（スクリーンショット）

## 6. リスクと対策

| リスク | 対策 |
|---|---|
| 70単元の品質低下 | ビルダーを再利用できる族に統一。単元固有部分はテキストとパラメータに限定 |
| 低性能GPU | 品質段階で Bloom・影・解像度を自動調整 |
| 日本語フォント | 3DラベルはCanvas描画（OSのフォントを利用） |
| WebGL不可 | フォールバック表示 |
