# 数宇宙 SU-KŪKAN

**高校数学 3D アニメーション図鑑** — 高等学校学習指導要領（平成30年告示 新課程）
数学I・数学A・数学II・数学B・数学III・数学C の **全82単元** を、ひとつの3D空間の中で理解する。

数式は星、証明は軌道運動、定理は空間の法則として現れる。
紙のグラフから空間へ持ち上げたとき、抽象式が実体を持つ瞬間を対象とする。

## 動かす

```bash
npm install
npm run dev           # 開発サーバー
npm run build         # dist/ に静的サイトとして出力
npm run preview       # build の結果をローカル確認
npm run build:single  # dist-single/su-kukan.html — 単一ファイル。サーバー不要
```

`dist-single/su-kukan.html` は **1ファイル完結**（2.7 MB、WebGLとKaTeXのフォント込み）です。
ダウンロードしてブラウザで直接開けば、サーバーもポートもネットワークも不要で動きます。

ブラウザで WebGL2 対応環境があれば動く。GPU が弱い環境では描画品質を自動で下げる
（右上「高/中/低」のボタンで手動変更も可）。

## 画面設計

**説明は字幕として演出に同期し、やがて消える。** 常駐パネルは置かない。
ステップが変わるたびに画面下部へ数式と本文が現れ、読み終えると下へ溶ける。
表示される面積は縦画面の 79〜84% までで、3Dが主役のまま。
停止中は文字が残り、`C` でいつでも呼び戻せる。

背景は全面透過を基本とし、テキストの可読性に必要な範囲（画面下端）にのみ
薄いグラデーションを置く。詳細テキストは必要なときだけ開く右パネル。

右パネルのスライダーでパラメータを動かせば、その場で図が変わる。

## 読み上げ

**読み上げ** ボタン（または `V`）で、ステップの文章と数式を日本語音声で読む。
外部ライブラリや API キーは使わず、端末に組み込まれた音声を Web Speech API で使う。

- ステップが変わると自動的に読み、**進行中の1文は必ず最後まで通す**。
  次のステップへ飛んでも途中では切らず、終えてから新しい文を読む
- 連続して飛ばしたりボタンを連打したりしても、待ち行列に残るのは最新の一文だけ
  なので、読み上げが積み重なって後追いになることはない
- 一時停止・読み上げオフで完全に止める
- 数式は LaTeX のままでは不自然な音になるため、`\frac` を「〜分の〜」、
  `^n` を「〜の n 乗」、`\sqrt` を「根号」など日本語へ変換してから読む
- 日本語話者は自動で選ぶ（Kyoko / Otoya / Nanami / Haruka / Google 日本語を優先）
- オンにした状態はブラウザに保存される

```
  CONTENT_GUIDE.md      教材台本の書き方
src/
  engine/               描画基盤
    App.js              レンダラ・合成・lesson ライフサイクル
    Stage.js            シーン、ライト、星空と星雲のシェーダ
    CameraRig.js        台本カメラ + ユーザーの軌道オフセット
    Sequencer.js        ステップ列の再生

    Materials.js        共有マテリアルライブラリ
    MathUtil.js         補間・イージング・乱数
  visuals/              可視化ビルダー 20 種
  content/              科目別の教材台本
  ui/                   星図 StarMap、DOM chrome
scripts/
  lint-text.mjs         文字化け・非日本語文字の検出（kanjidic2 照合）
  audit.mjs             全単元の parts 名を実ビルダーと突き合わせる
  sweep.mjs             全単元・全ステップを再生してページエラーを潰す
  preview-builders.mjs  全ビルダーを既定パラメータで描画
  parts.mjs             ビルダーの parts / params 一覧を生成
  steps.mjs             単元をステップ単位で撮影（台本の推敲用）
  shoot.mjs             ヘッドレス Chromium での描画検証
```

## 可視化の設計思想

| 領域 | 表現 |
|---|---|
| 二次曲線 | 円錐の平面切断。楕円・双曲線・放物線は実空間の同じ手続きから生まれる |
| 関数 | 3Dプロットと床への射影。接線・割線・面積・回転体をステップで出し入れ |
| 図形 | 発光ワイヤフレームと面の回転・展開 |
| 極限 | ε-δ の帯と収束する点列 |
| 確率 | サンプリングする群衆と 2^n の結果の木 |
| 複素数 | 複素数平面上の回転ベクトルと鏡像 |
| 数列 | 伸びる棒と螺旋上の点列 |

ビルダーは `docs/BUILDER_CONTRACT.md` の契約に従う。教材台本は
`docs/CONTENT_GUIDE.md` のスキーマに従う。どちらも追加は容易。

## 品質チェック

```bash
npm run check        # lint:text + build + audit + sweep をまとめて実行

npm run lint:text           # 全ソースの日本語 integrity
npm run lint:text -- <file> # 個別ファイル
npm run build               # 構文・import
npm run audit               # 全単元のビルダー登録と parts 名の検証
npm run sweep               # 全単元・全ステップを実 Animation して例外を潰す
npm run builders            # 全ビルダーを既定値で描画 → shots/builders/
npm run shot -- <unitId>    # 個別単元の描画 → shots/
npm run steps -- <unitId>   # その単元の全ステップを1枚ずつ
```

`lint-text.mjs` は kanjidic2（13108字）の日本語漢字集合と照合し、
日本語に存在しない漢字（＝簡体字など）と置換文字を検出する。
