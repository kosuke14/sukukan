星図

科目は世界を6つの星雲に分けている。単元は星。光ればそこで学ぶ。

操作方法

  • Space 再生 / 一時停止
  • ← → 前 / 次のステップ
  • C 字幕をもう一度表示
  • V 読み上げのオン / オフ
  • D 詳細テキストを開閉
  • Esc 星図へ戻る
  • R ステップ最初から再生
  • ドラッグ カメラを回す
  • ホイール ズーム

説明はステップの演出として表示されます。読むには画面下部に触れてください。 読み上げは端末の日本語音声を使います。数式は「a の x 乗」のように読みます。

WebGLを利用できません

ブラウザのハードウェアアクセラレーションを有効にして再読み込みしてください。
